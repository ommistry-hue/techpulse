# TechPulse – Growth + Comment Automation Plan (Oct 26, 2026)

## 1. Where we are (real data)

| Day | Uploads | New views | New subs |
|---|---|---|---|
| Oct 22 (Thu) | 9 | +2,915 | +3 |
| Oct 23 (Fri) | 13 | +3,180 | +1 |

- More uploads did NOT bring more views: views flat at ~3,000/day while uploads went 9 -> 17.
- Views per English Short fell: median 501 -> 199.
- Subscribers: 9 total from ~16,000 views (0.06%) - the biggest blocker for Level 1 (500 subs).
- Watch hours grew well: 4 -> 25.6.
- Comments: only 12 real viewer comments; 4 of them say "it's AI / AI slop" (largest group).

## 2. Why we are not growing (root causes)

1. **Same topic over and over** - 14 iPhone Duo videos in 3 days. Viewers get bored, YouTube shows us less, and it looks like a spam channel ("AI slop" comments).
2. **Wrong growth signal** - the volume check compares new videos with old ones (new ones always look better), so it raised uploads to 17 while real views per video fell.
3. **No reason to subscribe** - one-off videos, no series, no clear channel identity.
4. **Negative comments unanswered or answered wrongly** - one old reply falsely said "our team reviews topics".
5. **Weekend dip** - Sunday views lower; timing/weekday is not learned yet.

## 3. The plan

### Part A - Growth engine (fix the flat line)

| # | Fix | How it works (automatic) |
|---|---|---|
| A1 | **Topic cooldown** | Same product/story max 2 videos per 48 h (part 2s included); max 1 part 2 per hit, only if it beat the channel median by 2x. Every planner checks it (news, viral, breaking, part 2). |
| A2 | **Fair growth measurement** | Save each video's views when it is 24 h old. Compare 24-h views of this week vs last week. Uploads go back to **15/day** and only rise if 24-h views per video hold. |
| A3 | **Series = reasons to subscribe** | Videos grouped into series playlists ("iPhone Duo Saga", "AI News Daily", "Phone Deals India"). Videos say "Part 3 of the Foldable saga - follow so you don't miss Part 4". Pinned comment points to the series. |
| A4 | **Learn best times + weekdays** | Track 24-h views by upload hour and weekday per language; after 14 days shift slots to the best hours (weekend schedule can differ). |
| A5 | **Topic requests from viewers** | Comments like "make a video on X" go into a topic queue the planner prefers (if sources exist). |

### Part B - Comment system (every comment, every day)

**B1. Daily scan of ALL videos** (not only the last 8): every new viewer comment is read once an hour.

**B2. Each comment gets a type and an action:**

| Type | Action | Reply style |
|---|---|---|
| Question | Always reply (answer from the video's facts, or "not sure yet") | short, specific |
| "It's AI" / "AI slop" | Always reply, honest | "yep, it's AI-made - the facts are from the sources in the description. anything we got wrong?" |
| "Fake" / "wrong" | Always reply with sources + **automatic fact re-check** of that video | "fair to ask - this one's from The Verge and 9to5Mac, links below" |
| Fact correction | Re-check. If viewer is right: thank, **pinned correction**, "Correction:" added to description, lesson saved | "you're right, it's $99 per family member - pinned a correction, thanks" |
| Agree / opinion | Reply to ~60% at random (natural) | short, casual |
| Criticism (boring, bad voice) | Saved as feedback; reply sometimes; **never deleted** | "fair, we're working on it" |
| Topic request | Reply + add to topic queue (A5) | "good idea, noted" |
| Risky intent (piracy, mods) | Short warning reply, never instructions | |
| Abuse / hate / spam / links / scams | **Hidden automatically** (not deleted) | no reply |
| Emoji / one word | No reply | |

**B3. Natural behaviour:** reply only after 25+ min, max 3 per check, max 15 per day, every reply worded differently, same language as the comment, never claims to be human, never "our team".

**B4. Learning from comments (weekly):** comment types are counted per video and per format. Lessons go into the script rules automatically, e.g. many "AI slop" on one format -> that format used less; "boring voice" complaints -> more pace variety; repeated "wrong" -> stricter fact-check for that topic type.

**B5. Health score in the app:** positive vs negative comments per day and per video. If one video gets mostly negative comments, it is flagged and its topic/format is cooled down.

**B6. "Comments" tab in the app:** every viewer comment, its type, our reply, and a **"Needs you"** flag for rare cases (legal/copyright complaint, unverifiable correction, many negatives on one video). A **Hide** button for manual control.

**B7. Fix the old misleading reply** (Oct 16, "reviewed by our team") -> honest text. Needs owner OK (public edit).

### Part C - Transparency (fewer "AI slop" comments)

- Every script keeps a "why it matters to you" line (real analysis, not just reading news).
- Channel description: "AI-assisted tech news in 30 seconds - sources in every description." (owner adds in YouTube Studio).

## 5. Honest expectations

- These fixes target the real causes (repetition, weak subscribe reasons, honesty). Expect per-video views and subs/day to rise within ~1 week.
- Level 1 (500 subs + 3M Shorts views by Nov 21) still needs a few viral Shorts; the plan raises the chances, it cannot guarantee them.
- Never buy views/subs/comments; never delete honest criticism; never pretend to be human.
